# PCB-assembly-SCARA-
In this repository you will find all the code for our Robotics and Digital Control project which consists in building an RRP SCARA that places SMD like resistors, LEDs &amp; buttons in a PCB. 


Authors: Sebastián Escobar Restrepo, Marzuq Gallego, Santiago Ortiz, Laura Gutiérrez. 

Professors: Mario Giraldo & Manuel Ortiz 

Universidad EIA


Currently we are in development phase, doing preliminary designs in mechanics, robotics, software & electronics.
